# BOS RASTINA - PWA Task & Notebook App

Aplikasi pengingat tugasan dan buku nota harian untuk **Bos Rastina**.

## 🌟 Ciri-ciri Utama:
- **Tema Kuning & Putih (Yellow & White)**: Reka bentuk premium, kemas, dan profesional.
- **Buku Nota & Senarai To-Do**: Catat pekerjaan (contoh: *Buat Lesen*), deskripsi, dan status (*Siap* / *Belum Siap*).
- **Sambutan Ucapan & Quotes Harian MYS**: Ucapan selamat datang khas untuk Bos Rastina dan kata-kata motivasi harian yang sentiasa dikemaskini mengikut zon waktu Malaysia (UTC+8).
- **PWA Ready**: Boleh terus diinstall di Telefon Bimbit (Android/iOS) dan PC/Laptop.

## 🚀 Cara Muat Naik ke GitHub Pages:
1. Extract fail ZIP ini.
2. Muat naik semua fail dan folder ke Repository GitHub anda.
3. Buka **Settings** -> **Pages** -> Pilih branch `main` -> Klik **Save**.
4. Akses pautan GitHub Pages anda untuk mula menggunakan aplikasi!
